# System Patterns

---
## PhaseNotesStatusUpdates
*   [2026-01-12 15:13:23]
Convention: Keep phase and child task descriptions minimal (title only). When a child task status changes (esp. DONE), append a status update line into the parent phase's Notes panel entry (phase summary progress entry), separated by a blank line between updates. Do not duplicate detailed notes inside child task descriptions once recorded in the parent Notes entry.
